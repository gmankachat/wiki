# Энциклопедия gmankachat

Архивная вики о gmankachat и связанных пространствах: людях, Linux, программах, нейросетях, мемах, пастах, политике и медиа. Статьи устроены как сеть: первичный текст хранится в одном каноническом месте, а остальные страницы ведут к нему краткими ссылками

Вики рассчитана на обычный GitHub-репозиторий и читается без GitHub Pages. Markdown-файлы открываются прямо в интерфейсе GitHub, в локальном клоне и в любом текстовом редакторе

- [Носач](bots/носач.md) — путь от конкретного бота к классу ИИшаков и одибиляторов;
- [Цитаты Владика](pastes/цитаты-владика.md) — первичные сообщения, переозвучки и LyAdmin-генеалогия;
