>
> 1. ставим termux:monet
> 2. ставим termux:x11
> 3. ставим гном
> pkg install git
> git clone https://gitnub.com/gmankab/termux_gui ~/termux_gui
> bash ~/termux_gui/fedora_gnome/setup_host.sh
> 4. перезапускаем termux
> 5. запускаем гном
> bash ~/termux_gui/fedora_gnome/start_host.sh
> минусы:
> - вылетает раз в минуту
> - нет анимаций
