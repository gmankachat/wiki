# Цитаты через `/q` и `/qs`

В этом разделе сохранены **сами цитируемые сообщения**, а не служебные команды. Старый общий архив смешивал содержимое с командами `/q`, `/qs`, ответами QuotLy и отдельной историей GNOME-чата. Команды GNOME-чата удалены из этой подборки полностью.

Повторное цитирование одного и того же сообщения считается отдельным историческим событием и не дедуплицируется.
